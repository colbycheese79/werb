This edition, titled World English Reader’s Bible, is based on the World English Bible (WEB). The WEB is a modern English translation of the Scriptures and is in the public domain. This edition likewise remains in the public domain. This version uses the Majority Text as its Greek base. The wording of the translation has not been altered. However, verse numbers, section headings, and footnotes have been removed in order to present the text in a smooth and continuous reading format. The goal of this edition is to encourage sustained reading of the New Testament as complete books and letters, allowing the flow of thought to be experienced more naturally.
Book and chapter divisions are retained for navigation, but the text itself is presented without verse interruptions.
